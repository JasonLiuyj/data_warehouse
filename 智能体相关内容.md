#### How AI affects Data Development Career?

AI can affect our development process in three aspects :

* **model development**: we can utilize AI in adding fields, creating table and requirement development.

  In adding fields, its main effect is that it can help us add all related fields in development chain.

  In creating table, its main effect is that it can help us add important comments base on upstream table.

  In requirement development, AI couldn't do a good job at the moment.

* Data govern: its effect mainly reflect in field govern and repetitive model building.

  In repetitive model building, it mainly focus on recognize repetitive models by analysing all models in data warehouse.

  In field govern, it can recognize cold and warm data so that it can separate them even delete them.

* Task optimization: its main function is finding a suitable table as upstream table to improve it efficiency. We tend to choose big calibre table.

* **In testing process**, it also can help us in three aspects. Before test task running, we can utilize AI check whether SQL satisfy our need. After test task running, we can utilize AI check correction of our results. At last, we can utilize AI produce a report about this test task.

**With the advent of AI, we should convert our role from "know SQL, know business" to "know SQL, know business and know AI". We should conform to the trend of AI instead of insist on previous work.**
